The fonts of the looks of Neural Lens

The lens draws its looks in these fonts where a look asks for them. Each file
is its project's own and unchanged, taken on 2026-10-07 from the newest
release of the project on GitHub, and each is licensed under the SIL Open
Font License 1.1, whose text with the project's copyright line is in the
licenses folder of the lens. The lens adds them for its own process alone,
so nothing is installed on the computer.

Each font file's SHA-256 below is that of the file as published. A licence
text's is that of its text with LF line ends, since the copies in the
licenses folder have CRLF line ends.
